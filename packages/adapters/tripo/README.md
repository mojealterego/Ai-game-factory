# Tripo Adapter

Maps Factory 3D jobs to the Tripo API.

Supported capability families include text-to-3D, image-to-3D, multiview-to-3D, texture, mesh processing, retopology, rigging and animation where available to the connected account.

The adapter must use asynchronous task IDs, poll/webhook completion, persist provenance, and never expose the API key to the Android client.
