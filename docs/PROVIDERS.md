# Multi-Provider AI

Cataloged adapters include OpenAI, Google Gemini, Anthropic Claude, xAI Grok, Mistral, Cohere, Groq, DeepSeek, Qwen, OpenRouter, Together AI, Fireworks AI, Perplexity, Hugging Face, Replicate, Fal.ai, Stability AI, ElevenLabs, Runway, Kling, Luma, Azure OpenAI, AWS Bedrock, Google Vertex AI and custom OpenAI-compatible endpoints.

Each adapter records:
- endpoint
- capability matrix
- model policy
- connection status
- routing priority
- fallback policy
- permissions/scopes

Credentials are intentionally external to source control.
