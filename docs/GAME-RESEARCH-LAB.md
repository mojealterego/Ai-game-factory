# Game Research Lab

## Functions

- genre exploration
- mechanic search
- reference-game analysis
- platform fit analysis
- audience hypotheses
- mechanic combinations
- design constraints
- trend snapshots
- concept batch generation
- GDD synthesis

## Ludo adapter

The adapter supports Ludo API/MCP where credentials and plan permit it. It normalizes game ideation and asset-generation responses into Factory artifacts.

## Evidence

Research findings store source URL, retrieval timestamp, source type, extracted claim, confidence and project association.

The Lab informs decisions; it does not silently copy protected game content.
