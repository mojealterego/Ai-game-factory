# No-Code Agent Builder

## Graph nodes
Trigger, Intent, Planner, Provider Router, Tool, Memory, Approval Gate, Executor, QA, Evidence, Output.

## Agent controls
- model/provider selection
- fallback model
- tool allowlist
- permissions
- approval requirements
- memory policy
- budget policy
- retry policy
- evidence requirements
- test cases
- deployment state

## Deployment lifecycle
Draft → Validate → Test → Approval → Deploy → Observe → Pause/Resume → Version/Rollback.
